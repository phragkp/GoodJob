🚨

วิเคราะห์สถิติอุบัติเหตุ (2018–2025)

ศึกษารวบรวมข้อมูลอุบัติเหตุทางถนนย้อนหลัง 8 ปี กว่า 3,567,766 รายการ ครอบคลุม 77 จังหวัดทั่วประเทศไทย

🔍

ปัจจัยเสี่ยงและพฤติกรรม

วิเคราะห์ความสัมพันธ์ระหว่างช่วงเวลา ประเภทยานพาหนะ และพฤติกรรมเสี่ยงเพื่อระบุปัจจัยที่มีผลต่อระดับความรุนแรงอย่างมีนัยสำคัญ

💡

การพยากรณ์ระดับความรุนแรง (Severity)

นำ Machine Learning มาจำแนกระดับความรุนแรงผู้บาดเจ็บเพื่อการจัดสรรทรัพยากรทางการแพทย์อย่างมีประสิทธิภาพ

วัตถุประสงค์ของโครงการ

01

วิเคราะห์ปัจจัยเสี่ยง

ศึกษาและระบุปัจจัยสำคัญที่มีผลต่อการเกิดความรุนแรงของอุบัติเหตุทางถนนในประเทศไทย

02

พัฒนาโมเดลพยากรณ์

สร้างและฝึกฝนโมเดล Machine Learning หลากหลายอัลกอริทึมเพื่อคาดการณ์ระดับความรุนแรงของผู้บาดเจ็บ (Severity Levels)

03

เปรียบเทียบประสิทธิภาพ

ประเมินและเปรียบเทียบประสิทธิภาพของแต่ละโมเดล (Accuracy, Precision, Recall, F1-Score) เพื่อค้นหาอัลกอริทึมที่แม่นยำที่สุด

04

พัฒนาระบบแสดงผล

สร้าง Web Application เพื่อนำเสนอข้อมูลและผลการพยากรณ์ให้อยู่ในรูปแบบ Dashboard ที่ใช้งานง่ายและโต้ตอบได้เรียลไทม์

กระบวนการวิเคราะห์ข้อมูล (CRISP-DM Framework)

ขั้นตอนที่ 1

Business Understanding

กำหนดเป้าหมายเพื่อศึกษาปัจจัยเสี่ยงและพยากรณ์ระดับความรุนแรงอุบัติเหตุทางถนนในประเทศไทย

ขั้นตอนที่ 2

Data Understanding

ทำ EDA ด้วย Histogram, Heatmap และ Boxplot ตรวจสอบการกระจายตัวและค่าที่ขาดหายของข้อมูล 3.5 ล้านรายการ

ขั้นตอนที่ 3

Data Preparation

ลบข้อมูลซ้ำ ทำ Feature Engineering แบ่งช่วงเวลา จัดกลุ่มอายุ และแปลงรหัสตัวแปรเชิงกลุ่ม (One-Hot Encoding)

ขั้นตอนที่ 4

Modeling

แบ่งข้อมูล Train 70% / Test 30% เพื่อทดสอบ 4 โมเดล: Logistic Regression, ANN, Random Forest และ SVM

ขั้นตอนที่ 5

Evaluation

วัดประสิทธิภาพของโมเดลด้วยค่า Accuracy, Precision, Recall, F1-Score และ Confusion Matrix

ขั้นตอนที่ 6

Deployment

พัฒนา Web Application แสดงผล Dashboard และระบบประเมินความรุนแรงเรียลไทม์แก่ผู้ใช้งาน

วิเคราะห์ปัจจัยสำคัญที่มีผลต่อความรุนแรง

จากการวิเคราะห์ด้วยเทคนิค Feature Importance พบว่าปัจจัยสำคัญที่มีผลต่อระดับความรุนแรงของอุบัติเหตุทางถนนอย่างมีนัยสำคัญ ได้แก่:

  • ประเภทยานพาหนะ (Vehicle Type): รถจักรยานยนต์มีอัตราการบาดเจ็บระดับวิกฤต (รุนแรงมาก) สูงที่สุดคิดเป็น 68% ของเคสทั้งหมด
  • ช่วงเวลาที่เกิดเหตุ (Time of Day): ช่วงเวลาค่ำและดึก (18:00 - 06:00 น.) มีสัดส่วนความรุนแรงสูงกว่าช่วงอื่น
  • กลุ่มอายุผู้ประสบเหตุ (Age Group): ช่วงอายุวัยรุ่น (15-24 ปี) และผู้สูงอายุ มีความเสี่ยงต่อการเกิดความรุนแรงระดับสูง

เลือกจังหวัดเพื่อดูสถิติเชิงพื้นที่ (แบ่งตามภูมิภาค)

จังหวัดที่เลือก: กรุงเทพมหานคร

สรุปสถานการณ์: สถิติสะสมสูงที่สุดในประเทศ มักเกิดบนสายหลักและทางแยก ยานพาหนะหลักคือ รถจักรยานยนต์
